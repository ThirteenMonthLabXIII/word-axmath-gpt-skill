# 数学排版规则：首轮制作与检查

本文件是分页选项、编号、缩进、空格、题图和图号的统一规范。用户当前任务的要求优先；整册排版应用完整标准，局部修改只处理授权范围，保留已调好的格式和空段。练习册留白、页首、整题同页及标题分级见 [练习册排版标准](MATH_LAYOUT_REFERENCE.md)。仅排版时保留现有可编辑公式，不触发 AxMath 转换。

| 自动编号、括号、缩进或编号后的空格 | [二、题号和正文](#二题号和正文) 与 [编号结构](NUMBERING_AND_OUTLINE.md) |
| 文字和公式之间有空格 | [三、文字与公式](#三文字与公式) |

## 一、四项分页选项全部关闭

整册排版或用户要求全文关闭时，输出稿中**所有段落**的 Word“换行和分页”页的四个复选项均为关闭：孤行控制（`widowControl`）、与下段同页（`keepNext`）、段中不分页（`keepLines`）、段前分页（`pageBreakBefore`）。这包括章、节及分类标题、题干、小问、题图、图号、空段落，以及表格、文本框、页眉、页脚、脚注和尾注等故事中的段落。不要漏掉标题从 Heading 或其他样式继承的选项。

1. 检查段落直接属性、段落样式 `basedOn` 链和 `docDefaults`；同名属性由更近的层级覆盖。移除直接属性可能重新暴露样式里的 `true`；Word 的默认值也可能生效。不能把“没有 `w:pPr` 项”当成已关闭。
2. 需要关闭继承值时，在正确层级显式设为关闭（OOXML 如 `w:val="0"`，Word COM 的对应 `ParagraphFormat` 属性为 `0`），随后核对每段有效值；检查既有文件时也须处理已启用的值。不要修改字体、公式对象或不相关页面内容。
3. **不要为排版启用这四项**，不新加手动分页符。保留原有分节、题意所需的换行和用户要求的真实 Enter 空段。需要留白或让题目另起页时，用普通 Enter 段落规划并检查真实分页；题目不能完整同页时说明实际情况，不通过分页选项掩盖。
4. 检查 OOXML 后还要在真实 Word 确认有效 `WidowControl`、`KeepWithNext`、`KeepTogether`、`PageBreakBefore` 均为 `0`；优先用下方的后台 Word 只读检查工具覆盖各 story，处理其未决项。对象或故事无法覆盖时列为未完成。分页选项全部关闭不等于删除题干中的自然换行或把所有内容强行合并成一段。

## 二、题号和正文

按 [编号结构](NUMBERING_AND_OUTLINE.md) 先读取 Word 实际显示的列表编号及重启位置，再物化为普通文字并解除自动列表/编号域。保留原序号、跳号、星号、章节与小问的逻辑关系和顺序；不可依据缩进猜题号，也不能先删除列表丢掉显示值。

- 确认属于编号的数字用半角阿拉伯数字，括号和编号后的句点用英文半角；主问题号、例题号及每个小题右括号后各紧跟一个句点，如 `1.设…`、`例3.设…`、`(1).求…`、`*19.(1).…`。仅处理确认的编号；公式、坐标、正文括号及参考文献按原意保留。
- 编号内部和编号后**零空格**：`例`、星号、数字、括号、句点及其后的文字或公式紧接，不放普通/全角/不间断空格、Tab 或悬挂对齐填充。检查跨 run 的标签及与公式对象的边界；段落开头不以空格或 Tab 模拟缩进。
- 整册新排时文字默认楷体，正文左右各缩进 3 个字符，首行和悬挂缩进为零；若用户说已设置好或要求保留，记录并保留既有设置。各级题文在上述缩进后的正文左边界对齐；删除编号用制表位，不凭空改表格几何。标题、图和图号按语义排版，不把正文缩进一键应用到所有角色。
- 避免全局 `paragraph.text = ...`、清空整个段落或全局字符替换；这些操作可能丢失公式、图像、域、书签和运行格式。只修改确认的编号文本和段落属性，并保护原文与公式对象。

## 三、文字与公式

正文文字与前后紧邻的**行内公式对象**之间零空格、零 Tab。例如 `设` + AxMath `x` + `满足`，三者直接相邻。检查公式前后跨多个 run 的普通空格、全角空格、不间断空格和 Tab；检查 `w:object` 内真实 `Equation.AxMath`、OfficeMath 及其他经辨认的公式边界。不得用文本提取结果为空就假定没有公式。

仅处理“文字 ↔ 公式”边界及编号后的空白，不删英文单词之间、题干内部有实际意义的空格，也不进入 AxMath/OLE 或 OfficeMath 对象内部修改数学语义。额外可见间距还可能来自字体、Word 中西文自动间距、公式预览或对象几何：先在 Word 放大核实原因；未经来源和公式语义核实，不全局缩放对象或更换预览。无法安全去除时记录具体位置。

## 四、题图与图号

先从来源建立“题号 → 图片或分图 → 图号 → 正文引用”清单。题图与其对应图号分别水平居中；图号紧贴图片正下方，不能留在左侧、侧边或错误题目旁。多个分图可共享正确图号；能同页时通过 Enter 空段规划，不能用分页选项强制同页。无图号且归属明确时可写 `第 N 题图`，归属不明先核实。

图片嵌入段落时，图片所在段落及图号段落分别居中；浮动图、组合图或由表格/形状组成的图，必须核对相对于正文区或单元格的**实际中心位置**，单看段落的 `w:jc=center` 不足以证明居中。图片与题文同段时，按真实对象关系安全拆分或定位，保持题干左对齐、图及图号居中；不覆盖段落文本或拆散分图。AxMath 公式对象不是题图，不能按图片批量处理。页眉页脚图标或对象需人工分类，不把它们误认作题图。

## 五、首轮门槛和验收

1. **冻结来源并盘点：** 保存源文件副本和 SHA-256；登记题号、小问、公式、题图、图号、表格与所属关系，调查段落与样式继承。已有自动列表先记录 Word 实际显示的编号，后物化为文本。不得将未经确认的标签、坐标或文本括号当作题号。
2. **生成前即应用：** 明确文字段落与题图/图号角色；整册排版时关闭所有段落的四个分页选项；保留用户已设置的字体与缩进，题号和公式边界不加空格；图和图号居中。章节标题单独列入样页，不能仅处理题目。不要先一键将全文左对齐，等终稿再补救。
3. **代表样页：** 至少覆盖章/节标题、主问题号及不同小问、文字前后的行内 AxMath、独立公式、含分图的题目及图号、已有自动列表和样式继承；在任务许可的软件环境里放大检查有效分页选项、编号/缩进/空格、图及图号的实际位置和 AxMath 可编辑性。未通过先修样页，再批量生成。
4. **只读结构检查：** 对冻结来源先定位，再对样页和最终候选检查。命令（不修改 DOCX；`--report` 不覆盖已有报告）：

   ```powershell
   python scripts\inspect_layout_rules.py "<候选稿.docx>" --report "<工作区>\LAYOUT_INSPECTION.json"
   python scripts\inspect_question_numbering.py "<候选稿.docx>"
   powershell -File scripts\inspect_word_pagination.ps1 -InputDocx "<候选稿.docx>" -Report "<工作区>\WORD_PAGINATION.json"
   ```

   `inspect_layout_rules.py` 报告直接、样式及默认值可确定的问题，也列出未明确指定的分页值、图形、需人工确认的编号候选和浮动图。`inspect_word_pagination.ps1` 在可验证的独立后台 Word 进程中只读打开文件，逐个 Word story 读取四项有效值；报告为新文件，返回码 `2` 或 `pagination_values_pass=false` 表示存在启用项或未决项。不同 story 的 Word 序号与 OOXML 段落序号可能不同，应结合 story、段落和位置定位。若不能确认独立 Word 进程、某 story 不可读或对象未覆盖，记录未完成；不得操作用户原有 Word 进程。

   工具不会修复文件，Word 检查也只覆盖四个分页值；**不能把报告为空或脚本成功运行当作整份文档验收通过**。`inspect_layout_rules.py` 将任何非零左右缩进列为 `NONZERO_INDENT` 候选，也可能将居中标题列为对齐候选；须按本次规定的三字符或用户原有缩进及段落角色人工判断，不能把符合要求的值清零。图片清单必须与来源逐一核对；绘图对象、表格图、组合图和图号的位置均需人工核验。
5. **最终候选：** 对全部页面、所有标题和题组核实四项分页设置有效值、普通文字编号/半角标点、规定的缩进及编号和公式边界零空格；逐图核对图片和图号是否居中、归属及位置。保留正文、题目顺序、图形、表格、现有公式语义和答题空段。结构报告、对象数、页面缩略图或代表样页都不能代替逐页视觉和内容检查。实际无法验证的项目不得标为通过；修复后重查受影响部分，并以最终稿哈希绑定结果。
